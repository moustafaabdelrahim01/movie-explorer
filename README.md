# Movie Explorer

A responsive movie discovery app built with React and Tailwind CSS, using the TMDB API.

**Live demo:** https://movie-explorer-seven-wine.vercel.app

## Features

- Browse this week's trending movies
- Search movies with debounced input
- Save favorites (stored in localStorage)
- Dark mode, remembered between visits
- Movie details page with genres, rating, overview, and trailer
- Responsive design for desktop and mobile

## Built with

- React
- React Router
- Tailwind CSS
- Vite
- TMDB API

## Run locally

1. Clone the repository and install dependencies:

```bash
git clone https://github.com/moustafaabdelrahim01/movie-explorer.git
cd movie-explorer
npm install
```

2. Get a free API key from [TMDB](https://www.themoviedb.org/settings/api).

3. Create a `.env` file in the project root:

```
VITE_TMDB_KEY=your_api_key_here
```

4. Start the development server:

```bash
npm run dev
```
